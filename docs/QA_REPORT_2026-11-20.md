## Coverage boundaries

Production smoke checks and build outcomes are reported with the delivery message after deployment. External feeds can return fewer results or articles without publisher images; the app retains a placeholder for missing images. Source availability changes independently of this repository.

Android compile validation does not establish real-device behavior. Native Google sign-in, push delivery and platform permissions require runtime acceptance checks. iOS/macOS builds require macOS. Native Firebase remains the previously configured project. The [Android follow-up](ANDROID_QA_2026-11-20.md) records subsequent notification and native news-service changes.

The checks are evidence for the exercised paths, not a claim that every possible defect has been eliminated.
